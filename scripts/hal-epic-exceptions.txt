# Exceptions to the HAL_ -> EPIC_ rename (scripts/rename-hal-epic.sh /
# .awk). Tab-separated, 3 fields: path, line, token.
#
# path/line = "*" means the token is a global wildcard exception: never
# renamed, anywhere in the tree. Used for tokens that are unambiguously
# a *foreign* API (STM32Cube's own, real function/type names, quoted in
# this repo's docs/comments purely as a reader-orientation comparison,
# never this project's own identifiers). Confirmed unambiguous by
# checking each prefix never otherwise appears as this project's own
# code (see docs/hal-epic-rename-plan.md's survey): our I2C driver is
# HAL_SSP_*, not HAL_I2C_*; our serial driver is HAL_USART_*, not
# HAL_UART_*; our IRQ API is HAL_IRQ_*, not HAL_NVIC_*; this project has
# no "PPP" peripheral; epic-tick's own API is epic_-prefixed, never
# HAL_GetTick/HAL_Delay.
#
# An exact path+line entry (not "*") is for a token that is genuinely
# ambiguous: the same literal text is both this project's own
# identifier in most places, and a foreign reference on this one
# specific line. Currently only HAL_StatusTypeDef, see the plan doc.
#
# Re-run the survey commands in docs/hal-epic-rename-plan.md before
# trusting this file after any further doc edits: line numbers shift.
