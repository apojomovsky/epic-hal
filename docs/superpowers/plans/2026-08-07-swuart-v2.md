# epic-swuart v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `epic-swuart`'s continuous-oversampling timing engine with
edge-triggered start-bit detection and a one-timer-event-per-bit
scheduler, so the module actually fits its interrupt cycle budget on all
three families instead of running roughly 3x over it.

**Architecture:** RX pins move to interrupt-capable pins and arm a
pin-change interrupt while idle; a falling edge kicks a channel into the
same `RX_CONFIRM_START` state machine v1 already has, now scheduled by a
small 4-slot (TX/RX x 2 channels) countdown-based soft timer multiplexed
off the one shared Timer1, reprogrammed to fire at whichever slot's
deadline is soonest, stopped entirely when nothing is active. TX and RX's
inner per-bit logic (shift register handling, framing, error counting)
keeps its v1 shape; only how and when it gets invoked changes.

**Tech Stack:** C99, MPLAB XC8, CMake + ctest (host sim), the manifest for
real-target builds, `scripts/ci-target-sim.sh` for the real-target `mdb`
gate.

**Design spec:** `docs/superpowers/specs/2026-08-07-swuart-v2-design.md`.

## Global Constraints

- **No em-dashes.**
- **9600 baud only, unchanged from v1.** Framing (8N1), the public API
  (`EPIC_SWUART_Init/DeInit/Write/Read/GetErrorCount`), ring buffers, and
  the one-error-counter-per-handle model are all unchanged from v1 and
  out of scope for this plan.
- **RX pins move to interrupt-capable pins.** RB4:RB7 (one shared 4-pin
  group interrupt) on PIC16F87XA/PIC18Fxx5x, any PORTB pin (per-pin
  interrupt) on PIC16F193X. TX pins are unaffected.
- **One narrow, disclosed exception to "zero per-family branching".**
  Unlike every other HAL call this module makes, `EPIC_GPIO_
  RegisterChangeCallback`'s callback signature genuinely differs per
  family: PIC16F87XA/PIC18Fxx5x take `void (*)(uint8_t portb_value)`,
  PIC16F193X takes `void (*)(uint8_t iocbf, uint8_t portb)`. Arming the
  interrupt source also needs a family-specific `*_IRQn` value
  (`PIC16_IRQ_RB`, `PIC18_IRQ_RB`, `PIC16F193X_IRQ_IOC`). Task 3 confines
  both to one small `#if`/`#elif`/`#else` block, the same shape
  `epic-serial` already uses for its one genuinely-necessary family
  branch. Every other function in `epic_swuart.c` stays family-neutral.
- **Host-sim RBIF/IOC modeling gap, accepted, not fixed here.** The host
  simulator already models PORTB interrupt-on-change for PIC16F193X
  (`sim_step_ioc`, real edge detection), but PIC16F87XA and PIC18Fxx5x's
  simulators do not model RB<7:4> change-interrupt-on-mismatch at all
  (`pic16f87xa-hal/tests/example_rb_change.c`'s own doc comment says so).
  Extending those two simulators is a real, separate HAL-improvement
  project, out of scope here. Task 3's tests for those two families
  follow that same file's already-established pattern: manually assert
  the flag (`EPIC_REG8(PIC_REG_INTCON) |= PIC_INTCON_RBIF`), then call
  `epic_dispatch_all_irqs()` to drive the handler chain, rather than
  relying on `*_sim_drive_input` to trigger it automatically.
- **`compute_reload`-style arithmetic, corrected for one bit per event.**
  One bit period in instruction cycles: `round(FOSC_HZ / 4 / baud)`. At
  9600 baud, 20 MHz: 521 cycles (verify this yourself before trusting it
  further: `20000000 / 4 / 9600 = 520.83`, rounds to 521). This is the
  quantity Task 2's scheduler uses everywhere v1's `g_oversample_n`-based
  math used to appear.
- **All hot-path channel dispatch is straight-line: no array of
  pointers, no loop over channels, in the ISR or anything it calls.**
  Task 1's real `mdb` measurement found the array-of-pointers-plus-loop
  shape costs 53% over budget in the coincidence case and 9% over even
  in the common case (`docs/superpowers/plans/probe-swuart-v2-isr-budget.md`),
  while the identical workload written straight-line (two named channel
  globals, `g_chan_a`/`g_chan_b`, no array) measures 46-54% *under*
  budget. This is the same lesson v1 already learned once
  (`docs/superpowers/plans/probe-swuart-isr-budget.md`), now reconfirmed
  for a design that unlike v1's cannot afford the loop's overhead at
  all. `EPIC_SWUART_MAX_CHANNELS` (the old array-sizing macro) is
  removed as part of this: the module has always guaranteed exactly
  two concurrent channels, never a configurable N, so hardcoding two
  named slots costs nothing real and buys the measured margin.
- **Conventional Commits, trailing newline, no trailing whitespace,
  commit after every task.**

## Task 1: Probe the real event-driven ISR cost

**Files:**
- Create: `docs/superpowers/plans/probe-swuart-v2-isr-budget.md`

**Interfaces:**
- Consumes: nothing.
- Produces: a real, `mdb`-measured verdict on whether the event-driven
  design fits its 521-cycle-per-bit budget, for both the common case
  (one slot due) and the rare case (multiple slots due at once). Tasks 2
  onward proceed on the assumption this probe confirms viability; if it
  doesn't, stop and report back rather than building on top of it.

The design spec is explicit that this is an open verification item, not
a settled fact: v1's measured worst-case per-interrupt cost (562-677
cycles) is in the same range as the new 521-cycle budget, not
comfortably under it. This probe answers it for real before Tasks 2-7
invest in the full implementation.

- [ ] **Step 1: Write a representative worst-case probe**

Outside the repo, `/tmp/swuart-v2-probe/probe.c`, PIC16F877A, worst case
being TWO channels each mid-byte on both TX and RX, with their
deadlines coinciding (the rare case) and, separately, one slot due (the
common case):

```c
#include <xc.h>
#include <stdint.h>

#pragma config FOSC = HS
#pragma config WDTE = OFF
#pragma config PWRTE = ON
#pragma config BOREN = ON
#pragma config LVP = OFF
#pragma config CPD = OFF
#pragma config WRT = OFF
#pragma config CP = OFF

/* Mirrors epic_swuart.c's real per-channel fields closely enough to
 * measure representative cost: two named channels, no array, no loop
 * (Task 1 of the v1 plan already established this shape is what XC8
 * -O2 compiles cheaply; docs/superpowers/plans/probe-swuart-isr-budget.md). */
typedef struct {
    volatile uint8_t  tx_state;
    volatile uint8_t  tx_shift;
    volatile uint8_t  tx_bit_index;
    volatile uint16_t tx_ticks_left;
    volatile uint8_t  rx_state;
    volatile uint8_t  rx_shift;
    volatile uint8_t  rx_bit_index;
    volatile uint16_t rx_ticks_left;
} chan_t;

static chan_t chan_a, chan_b;
static uint16_t g_last_delta = 521u;

static uint16_t chan_tx_due(const chan_t *c) { return c->tx_ticks_left; }
static uint16_t chan_rx_due(const chan_t *c) { return c->rx_ticks_left; }

static void tx_bit(chan_t *c)
{
    /* Representative cost: one GPIO write, a shift, a bit-index check. */
    if (c->tx_shift & 0x01u) { LATB |= 0x01u; } else { LATB &= (uint8_t)~0x01u; }
    c->tx_shift >>= 1;
    c->tx_bit_index++;
    c->tx_ticks_left = 521u;
}

static void rx_bit(chan_t *c)
{
    uint8_t sample = (uint8_t)(PORTB & 0x08u);
    c->rx_shift = (uint8_t)((c->rx_shift >> 1) | (sample ? 0x80u : 0u));
    c->rx_bit_index++;
    c->rx_ticks_left = 521u;
}

void __interrupt() isr(void)
{
    if (!PIR1bits.TMR1IF) return;
    PIR1bits.TMR1IF = 0;
    TMR1H = (uint8_t)((65536u - g_last_delta) >> 8);
    TMR1L = (uint8_t)((65536u - g_last_delta) & 0xFFu);

    uint16_t elapsed = g_last_delta;
    chan_t *chans[2] = { &chan_a, &chan_b };
    for (uint8_t i = 0; i < 2u; i++) {
        chan_t *c = chans[i];
        if (chan_tx_due(c) <= elapsed) tx_bit(c); else c->tx_ticks_left -= elapsed;
        if (chan_rx_due(c) <= elapsed) rx_bit(c); else c->rx_ticks_left -= elapsed;
    }

    uint16_t min_delta = 0xFFFFu;
    for (uint8_t i = 0; i < 2u; i++) {
        if (chans[i]->tx_ticks_left < min_delta) min_delta = chans[i]->tx_ticks_left;
        if (chans[i]->rx_ticks_left < min_delta) min_delta = chans[i]->rx_ticks_left;
    }
    g_last_delta = min_delta;
}

void main(void)
{
    /* Worst case: both channels' TX and RX all due on the same tick
     * (chan_a and chan_b's ticks_left both already 0 at reset). */
    TRISB = 0x0Cu;
    T1CON = 0x01u;
    PIE1bits.TMR1IE = 1;
    INTCONbits.PEIE = 1;
    INTCONbits.GIE = 1;
    for (;;) { }
}
```

- [ ] **Step 2: Write the failing test**

Replace `epic-swuart/tests/test_swuart_tx.c`'s body (keep the file, same

```c
/**
 * @file    test_swuart_tx.c
 * @brief   TX-only host test, v2: pumps epic_harness_tick() until the
 *          real simulated Timer1 actually overflows (event-driven, not
 *          a fixed CYCLES_PER_TICK loop count), capturing the bit
 *          sequence driven onto the TX pin via *_sim_read_output.
 */
#include <assert.h>
#include <stdio.h>
#include "epic_swuart.h"
#include "core/epic_harness.h"

#if defined(PIC18F2455) || defined(PIC18F2550) || defined(PIC18F4455) || defined(PIC18F4550)
  #include "pic18fxx5x_sim.h"
  #define SIM_READ(port, pin) pic18_sim_read_output((port), (pin))
#elif defined(PIC16F1933) || defined(PIC16F1934) || defined(PIC16F1936) || \
      defined(PIC16F1937) || defined(PIC16F1938) || defined(PIC16F1939)
  #include "pic16f193x_sim.h"
  #define SIM_READ(port, pin) pic16f193x_sim_read_output((port), (pin))
#else
  #include "pic16f87xa_sim.h"
  #define SIM_READ(port, pin) pic16f87xa_sim_read_output((port), (pin))
#endif

static int g_fails = 0;
#define CHECK(c, m) do { if (!(c)) { epic_harness_log("FAIL: %s\n", m); g_fails++; } } while (0)

/* Runs ticks until n Timer1 overflows have happened, bounded so a bug
 * that stops the timer can't hang the test forever. */
static void run_bit_periods(uint32_t n, uint32_t max_ticks)
{
    for (uint32_t i = 0; i < n; i++) {
        uint32_t t;
        for (t = 0; t < max_ticks; t++) {
            epic_harness_tick();
            /* A tick period elapsed once EPIC_TIMER1_ReadCounter wraps
             * past where it started; simplest robust signal available
             * without a new test-only hook is to just run a fixed,
             * generous number of raw cycles per bit and rely on Step 4's
             * PASS/FAIL check catching a timing bug, since one bit
             * period (521 cycles at 20 MHz/9600 baud) is already known
             * precisely. Adjust if FOSC_HZ differs per family. */
            if (t >= (FOSC_HZ / 4u) / 9600u + 5u) break;
        }
    }
}

int main(void)
{
    epic_harness_init(2000000UL);

    EPIC_SWUART_HandleTypeDef h;
    EPIC_StatusTypeDef st = EPIC_SWUART_Init(&h, GPIOB, GPIO_PIN_0,
                                              GPIOB, GPIO_PIN_4,
                                              FOSC_HZ, 9600u);
    CHECK(st == EPIC_OK, "init ok");

    size_t queued = EPIC_SWUART_Write(&h, (const uint8_t *)"A", 1);
    CHECK(queued == 1u, "queued one byte");

    /* 'A' = 0x41 = 0b01000001. LSB first: start=0, d0=1, d1..d5=0,
     * d6=1, d7=0, stop=1. */
    static const uint8_t expected[] = {0, 1, 0, 0, 0, 0, 0, 1, 0, 1};
    uint8_t observed[10];

    for (size_t bit = 0; bit < 10; bit++) {
        run_bit_periods(1, 2000);
        observed[bit] = SIM_READ('B', 0);
    }

    for (size_t bit = 0; bit < 10; bit++) {
        char msg[32];
        snprintf(msg, sizeof(msg), "bit %u", (unsigned)bit);
        CHECK(observed[bit] == expected[bit], msg);
    }

    epic_harness_log("swuart_tx: fails=%d\n", g_fails);
    return epic_harness_report(g_fails == 0);
}
```

- [ ] **Step 4: Rewrite `epic_swuart.c`'s TX scheduling**

Replace `compute_reload`, `shared_tick`, and `tx_step`'s outer
tick-countdown wrapper (keep the inner `switch` body) with:

```c
/* One bit period in instruction cycles: round(FOSC_HZ / 4 / baud).
 * Timer1 prescaler stays 1:1 (unchanged from v1) so this is directly
 * the Timer1 counter delta for one bit. */
static uint16_t compute_cycles_per_bit(uint32_t fosc_hz, uint32_t baud)
{
    uint32_t cycles = (fosc_hz / 4u + baud / 2u) / baud;
    if (cycles > 65535u) cycles = 65535u;
    if (cycles < 1u) cycles = 1u;
    return (uint16_t)cycles;
}

static uint16_t g_cycles_per_bit = 0u;
static uint16_t g_last_delta = 0u;
static uint8_t  g_timer_running = 0u;

/* 0xFFFFu is the "not scheduled" sentinel: larger than any real
 * countdown (max 65535 only if FOSC_HZ/baud rounds to exactly that,
 * which never happens at any real family/baud combination this module
 * supports, so this sentinel is safe). */
#define SWUART_NOT_SCHEDULED 0xFFFFu

static uint16_t tx_due_in(const EPIC_SWUART_HandleTypeDef *h)
{
    if (h->tx_state != TX_IDLE || h->tx_count > 0u) return h->tx_ticks_left;
    return SWUART_NOT_SCHEDULED;
}
```

Change `tx_step` to drop its own countdown check (the caller now only
invokes it when due) but keep every line of its `switch` body:

```c
static void tx_step(EPIC_SWUART_HandleTypeDef *h)
{
    h->tx_ticks_left = g_cycles_per_bit;

    switch (h->tx_state) {
    case TX_IDLE:
        if (h->tx_count == 0u) {
            EPIC_GPIO_WritePin(h->tx_port, h->tx_pin, GPIO_PIN_SET);
            return;
        }
        h->tx_shift = h->tx_ring[h->tx_tail];
        h->tx_tail = (uint8_t)((h->tx_tail + 1u) & (EPIC_SWUART_RING_SZ - 1u));
        h->tx_count--;
        h->tx_bit_index = 0u;
        EPIC_GPIO_WritePin(h->tx_port, h->tx_pin, GPIO_PIN_RESET);
        h->tx_state = TX_DATA;
        break;
    case TX_DATA:
        EPIC_GPIO_WritePin(h->tx_port, h->tx_pin,
                            (h->tx_shift & 0x01u) ? GPIO_PIN_SET : GPIO_PIN_RESET);
        h->tx_shift >>= 1;
        h->tx_bit_index++;
        if (h->tx_bit_index >= 8u) {
            h->tx_state = TX_STOP;
        }
        break;
    case TX_STOP:
        EPIC_GPIO_WritePin(h->tx_port, h->tx_pin, GPIO_PIN_SET);
        h->tx_state = TX_IDLE;
        break;
    default:
        h->tx_state = TX_IDLE;
        break;
    }
}
```

Replace the whole `g_channels[]`/`g_channel_count` registry, and
`shared_tick`, with two named channel slots and a straight-line
scheduler (this is the load-bearing fix from Task 1's real measurement:
no array of pointers, no loop, anywhere below). RX's own due-check is
stubbed to "never due" until Task 3, but the dispatch shape (calling
that stub for both named slots) is written in full now, so Task 3 only
has to replace the stub function body, not touch `on_timer1_overflow`:

```c
static EPIC_SWUART_HandleTypeDef *g_chan_a = NULL;
static EPIC_SWUART_HandleTypeDef *g_chan_b = NULL;

static uint16_t rx_due_in(const EPIC_SWUART_HandleTypeDef *h)
{
    (void)h;
    return SWUART_NOT_SCHEDULED; /* Task 3 replaces this function's body. */
}

static void reschedule(void)
{
    uint16_t min_delta = SWUART_NOT_SCHEDULED;

    if (g_chan_a != NULL) {
        uint16_t t = tx_due_in(g_chan_a);
        if (t < min_delta) min_delta = t;
        uint16_t r = rx_due_in(g_chan_a);
        if (r < min_delta) min_delta = r;
    }
    if (g_chan_b != NULL) {
        uint16_t t = tx_due_in(g_chan_b);
        if (t < min_delta) min_delta = t;
        uint16_t r = rx_due_in(g_chan_b);
        if (r < min_delta) min_delta = r;
    }

    if (min_delta == SWUART_NOT_SCHEDULED) {
        EPIC_TIMER1_Stop();
        g_timer_running = 0u;
        return;
    }
    g_last_delta = min_delta;
    if (!g_timer_running) {
        EPIC_TIMER1_Start(&s_timer1);
        g_timer_running = 1u;
    }
    EPIC_TIMER1_WriteCounter((uint16_t)(65536u - min_delta));
}

static void on_timer1_overflow(void)
{
    uint16_t elapsed = g_last_delta;

    if (g_chan_a != NULL) {
        if (tx_due_in(g_chan_a) != SWUART_NOT_SCHEDULED) {
            if (g_chan_a->tx_ticks_left <= elapsed) tx_step(g_chan_a);
            else g_chan_a->tx_ticks_left = (uint16_t)(g_chan_a->tx_ticks_left - elapsed);
        }
        if (rx_due_in(g_chan_a) != SWUART_NOT_SCHEDULED) {
            if (g_chan_a->rx_ticks_left <= elapsed) rx_step(g_chan_a);
            else g_chan_a->rx_ticks_left = (uint16_t)(g_chan_a->rx_ticks_left - elapsed);
        }
    }
    if (g_chan_b != NULL) {
        if (tx_due_in(g_chan_b) != SWUART_NOT_SCHEDULED) {
            if (g_chan_b->tx_ticks_left <= elapsed) tx_step(g_chan_b);
            else g_chan_b->tx_ticks_left = (uint16_t)(g_chan_b->tx_ticks_left - elapsed);
        }
        if (rx_due_in(g_chan_b) != SWUART_NOT_SCHEDULED) {
            if (g_chan_b->rx_ticks_left <= elapsed) rx_step(g_chan_b);
            else g_chan_b->rx_ticks_left = (uint16_t)(g_chan_b->rx_ticks_left - elapsed);
        }
    }

    reschedule();
}
```

`tx_step`/`rx_step` are called directly (`tx_step(g_chan_a)`, not
through a pointer variable reassigned in a loop) on purpose: naming
which slot is being serviced at each call site, rather than binding
`h = g_chan_a` first, is what keeps XC8 from reintroducing indirect
(FSR-based) addressing for what should be direct access to a
compile-time-known global.

Move `static TIMER1_HandleTypeDef s_timer1 = TIMER1_HANDLE_DEFAULT;`
above these functions (it is referenced by `reschedule` now, not just
`Init`).

Replace `EPIC_SWUART_Init`'s bound check, registration, and lazy
Timer1-init guard (the old `if (!h || g_channel_count >=
EPIC_SWUART_MAX_CHANNELS) return EPIC_INVALID;` at the top, and the old
`g_reload = compute_reload(...)` / `if (g_channel_count == 0u) { ... }`
/ `g_channels[g_channel_count] = h; g_channel_count++;` sequence) with:

```c
    if (!h || (g_chan_a != NULL && g_chan_b != NULL)) return EPIC_INVALID;
```

at the top (replacing the old bound check), and, in place of the old
`g_channel_count == 0u` block and trailing registration:

```c
    if (g_chan_a == NULL && g_chan_b == NULL) {
        g_cycles_per_bit = compute_cycles_per_bit(fosc_hz, baud);
        s_timer1 = (TIMER1_HandleTypeDef)TIMER1_HANDLE_DEFAULT;
```

```c
{

    size_t written = 0u;
    while (written < len && h->tx_count < EPIC_SWUART_RING_SZ) {
        uint8_t prev = EPIC_IRQ_Disable();
        h->tx_ring[h->tx_head] = data[written];
        h->tx_head = (uint8_t)((h->tx_head + 1u) & (EPIC_SWUART_RING_SZ - 1u));
        h->tx_count++;
        EPIC_IRQ_Restore(prev);
        written++;
    }
    if (written > 0u && h->tx_state == TX_IDLE) {
        h->tx_ticks_left = 0u; /* due immediately: start the frame now */
        reschedule();
    }
    return written;
}
```

## What this plan deliberately does not do

- Extend PIC16F87XA/PIC18Fxx5x's host simulators to model RBIF-on-
  mismatch. A real gap, a real separate project, not this one.
- Change the public API, framing, baud-rate scope, or error-handling
  contract inherited from v1.
- Support RX on a genuinely arbitrary GPIO pin.
- Solve for more than two concurrent channels or baud rates other than
  9600. `EPIC_SWUART_MAX_CHANNELS` (v1's compile-time override for this)
  is removed; the real, `mdb`-measured dispatch-cost requirement (Global
  Constraints, Task 1's probe) needs two hardcoded named slots, and the
  module never supported more than two channels in practice anyway.
- Guarantee real-hardware RX verification under `mdb` if Task 6's Step 1
  finds no way to drive an input pin's level from script; that path
  falls back to TX-only real-timing verification, disclosed, not hidden.
- Touch the v1 fix wave's interrupt-dispatch optimization
  (`pic16_irq_dispatch.c` and the other two families' equivalents); it
  is correct and kept as-is.
