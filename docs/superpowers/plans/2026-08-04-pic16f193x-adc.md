# ADC for pic16f193x-hal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Status: **implemented and cleared the §4 gate.** Peripheral #5 in
`docs/pic16f193x-plan.md` §7's roadmap table.

**Goal:** Land a `EPIC_ADC_*` driver for the 10-bit ADC (DS41364B
§16.0 in this datasheet's chapter numbering; confirm exact section
during implementation) through the §4 gate, with a real mitigation for
a documented silicon errata (Global Constraints).

**Architecture:** Mirrors `pic16f87xa_adc.h`'s select-then-start API
shape (`EPIC_ADC_SelectChannel`, `EPIC_ADC_Start`, poll-or-IRQ,
`EPIC_ADC_Read`). Channel count comes from the existing
`PIC16F193X_FAMILY_ADC_CH`-style capability macro
(`docs/pic16f193x-plan.md` §5 item 1), not hardcoded. Analog-pin setup
(ANSEL) is the caller's job via the existing GPIO driver, this driver
only touches ADCON0/ADCON1/ADRESL/H.

**Tech Stack:** C99, MPLAB XC8, gcc (host sim), CMake, GNU Make.

## Global Constraints

- C99, no compiler extensions. No em-dashes anywhere.
- Every register access is a compile-time-constant `PIC_REG_*` token.
- Handle-copy convention: copy by value, never store the pointer.
- **Standing warning**: every bit position here was re-derived from
  DS41364B and cross-checked against the installed DFP header's
  `_ADCON0_`/`_ADCON1_` `_POSN`/`_MASK` macros
  (`/opt/microchip/xc8/v3.10/pic/packs/Microchip.PIC12-16F1xxx_DFP/xc8/pic/include/proc/pic16f1937.h`).
  Timer1 shipped with a wrong bit position (`PIC_T1CON_TMR1CS` at bit
  1, copied from `pic16f87xa`'s classic-PIC16 T1CON, real field is
  bits 7:6) from a transcription without this cross-check. Never trust
  a bit position from another family's driver or memory alone.
- **Errata (DS80000479, `docs/pic16f193x-plan.md` §1)**: "ADC may not
  complete at FOSC > 8 MHz." This is a real correctness constraint,
  not a note. `ADCON1<ADCS2:0>` selects the ADC clock; this driver's
  default (`ADC_HANDLE_DEFAULT`) uses the dedicated RC oscillator
  encoding (`ADC_CLOCK_FRC`, independent of Fosc, always safe) rather
  than an Fosc-derived divisor, so callers who don't override
  `ClockSource` are automatically errata-safe. `EPIC_ADC_Init` accepts
  Fosc-derived clock sources too (some applications need
  Fosc-synchronous timing) but the header must document that the
  caller is responsible for picking a divisor keeping the ADC clock
  period at or under the datasheet's safe threshold when Fosc > 8 MHz,
  this driver does not compute or validate that for them.

## Non-goals (not in this phase)

- None; the ADC's feature surface (channel select, start/poll/read,
  clock source, reference source, result format) is small enough to
  cover fully in one pass. FVR-as-reference (`ADPREF`/`ADNREF`
  selecting FVR) is included as a valid enum value since it costs
  nothing to expose, but the FVR peripheral itself
  (`docs/superpowers/plans/2026-08-04-pic16f193x-fvr.md`) must land
  and be enabled+ready before a caller actually selects it, this
  driver does not check FVR's ready state for them.

```c
/* Bank 1. ADCON0/ADCON1, DS41364B ADC chapter. Verified against the
 * installed DFP header (pic16f1937.h) _ADCON0_/_ADCON1_ POSN/MASK
 * macros; re-verify against DS41364B before relying on them,
 * especially the CHS<4:0> channel-count width and the ADCS<2:0>
 * clock-source encoding table below. */
#define PIC_ADCON0_ADON         PIC8_BIT(0)
#define PIC_ADCON0_GO_NDONE     PIC8_BIT(1)   /* Set to start; hardware clears when done. */
#define PIC_ADCON0_CHS_MASK     0x7CU         /* ADCON0<6:2>: CHS<4:0>, 5-bit channel select. */
#define PIC_ADCON0_CHS_SHIFT    2U
/* ADCON0 POR = 0x00 (confirm against DS41364B). */

#define PIC_ADCON1_ADPREF_MASK  0x03U         /* ADCON1<1:0>: positive reference select. */
#define PIC_ADCON1_ADNREF       PIC8_BIT(2)   /* ADCON1<2>: negative reference select. */
#define PIC_ADCON1_ADCS_MASK    0x70U         /* ADCON1<6:4>: clock source select. */
#define PIC_ADCON1_ADCS_SHIFT   4U
#define PIC_ADCON1_ADFM         PIC8_BIT(7)   /* ADCON1<7>: result format, 1=right-justified. */
/* ADCON1 POR = 0x00 (confirm against DS41364B). Re-derive the
 * ADCS<2:0> encoding table (Fosc/2, /8, /32, FRC, /4, /16, /64, FRC)
 * against DS41364B directly, this is the standard PIC mid-range ADC
 * clock table shape but was not independently re-confirmed
 * bit-for-bit against this specific datasheet's table text. */
```

```c
/**
 * @file    pic16f193x_adc.h
 * @brief   PIC16F193X 10-bit ADC driver.
 * @details Source: DS41364B ADC chapter. DS80000479 errata: ADC may
 *          not complete at FOSC > 8 MHz; ADC_HANDLE_DEFAULT uses
 *          ADC_CLOCK_FRC (Fosc-independent) to sidestep it by
 *          default, see the plan's Global Constraints for the full
 *          mitigation note. Full reference: MANUAL.md §16.
 */
#ifndef PIC16F193X_ADC_H
#define PIC16F193X_ADC_H

#include <stdint.h>
#include "core/hal_status.h"
#include "pic16f193x.h"   /* PIC16F193X_FAMILY_ADC_CH. */

#ifdef __cplusplus
extern "C" {
#endif

/** ADCON1<ADCS2:0>. Re-derive/confirm this table against DS41364B
 *  before trusting the numeric values (see Task 1's note). */
typedef enum {
    ADC_CLOCK_FOSC_2  = 0x0U,
    ADC_CLOCK_FOSC_8  = 0x1U,
    ADC_CLOCK_FOSC_32 = 0x2U,
    ADC_CLOCK_FRC_A   = 0x3U,   /**< Dedicated RC osc, Fosc-independent, errata-safe. */
    ADC_CLOCK_FOSC_4  = 0x4U,
    ADC_CLOCK_FOSC_16 = 0x5U,
    ADC_CLOCK_FOSC_64 = 0x6U,
    ADC_CLOCK_FRC_B   = 0x7U,   /**< Also FRC, per datasheet's redundant encoding. */
} ADC_ClockSourceTypeDef;

/** ADCON1<ADPREF1:0>. */
typedef enum {
    ADC_POSREF_VDD = 0x0U,
    ADC_POSREF_FVR = 0x3U,   /**< Requires FVR peripheral enabled+ready first, not checked here. */
} ADC_ReferencePosTypeDef;

typedef enum {
    ADC_NEGREF_VSS = 0x0U,
} ADC_ReferenceNegTypeDef;

typedef enum {
    ADC_FORMAT_LEFT_JUSTIFIED  = 0x0U,
    ADC_FORMAT_RIGHT_JUSTIFIED = 0x1U,
} ADC_ResultFormatTypeDef;

typedef struct {
    ADC_ClockSourceTypeDef  ClockSource;   /**< Default FRC, errata-safe. */
    ADC_ReferencePosTypeDef PosRef;
    ADC_ReferenceNegTypeDef NegRef;
    ADC_ResultFormatTypeDef Format;
} ADC_HandleTypeDef;

#define ADC_HANDLE_DEFAULT { .ClockSource = ADC_CLOCK_FRC_A, .PosRef = ADC_POSREF_VDD, .NegRef = ADC_NEGREF_VSS, .Format = ADC_FORMAT_RIGHT_JUSTIFIED }

EPIC_StatusTypeDef EPIC_ADC_Init(const ADC_HandleTypeDef *h);
EPIC_StatusTypeDef EPIC_ADC_DeInit(void);
EPIC_StatusTypeDef EPIC_ADC_SelectChannel(uint8_t channel);   /**< 0..PIC16F193X_FAMILY_ADC_CH-1. Caller must have set ANSEL via the GPIO driver first. */
void EPIC_ADC_Start(void);
uint8_t EPIC_ADC_IsConversionDone(void);
uint16_t EPIC_ADC_Read(void);   /**< 10-bit result, justified per Format. */

void ADC_IRQHandler(void) PIC8_WEAK;

#ifdef __cplusplus
}
#endif
#endif /* PIC16F193X_ADC_H */
```

```c
/**
 * @file    pic16f193x_adc.c
 * @brief   PIC16F193X ADC driver implementation.
 */
#include "peripherals/pic16f193x_adc.h"
#include "pic16f193x_sfr.h"
#include "pic16f193x_platform.h"

static void (*s_conv_cb)(void);

EPIC_StatusTypeDef EPIC_ADC_Init(const ADC_HandleTypeDef *h)
{
    if (!h) return EPIC_INVALID;

    uint8_t con1 = (uint8_t)(h->PosRef & PIC_ADCON1_ADPREF_MASK);
    if (h->NegRef) con1 |= PIC_ADCON1_ADNREF;
    con1 |= (uint8_t)(((uint8_t)h->ClockSource << PIC_ADCON1_ADCS_SHIFT) & PIC_ADCON1_ADCS_MASK);
    if (h->Format == ADC_FORMAT_RIGHT_JUSTIFIED) con1 |= PIC_ADCON1_ADFM;
    PIC8_REG8(PIC_REG_ADCON1) = con1;

    PIC8_REG8(PIC_REG_ADCON0) = PIC_ADCON0_ADON;   /* Channel 0 by default; SelectChannel overrides. */

    return EPIC_OK;
}

EPIC_StatusTypeDef EPIC_ADC_DeInit(void)
{
    PIC8_REG8(PIC_REG_ADCON0) = 0x00U;
    PIC8_REG8(PIC_REG_ADCON1) = 0x00U;
    s_conv_cb = 0;
    return EPIC_OK;
}

EPIC_StatusTypeDef EPIC_ADC_SelectChannel(uint8_t channel)
{
    if (channel >= PIC16F193X_FAMILY_ADC_CH) return EPIC_INVALID;
    uint8_t con0 = PIC8_REG8(PIC_REG_ADCON0);
    con0 = (uint8_t)((con0 & (uint8_t)~PIC_ADCON0_CHS_MASK)
                    | (uint8_t)((channel << PIC_ADCON0_CHS_SHIFT) & PIC_ADCON0_CHS_MASK));
    PIC8_REG8(PIC_REG_ADCON0) = con0;
    return EPIC_OK;
}

void EPIC_ADC_Start(void)
{
    PIC8_BIT_SET(PIC8_REG8(PIC_REG_ADCON0), PIC_ADCON0_GO_NDONE);
}

uint8_t EPIC_ADC_IsConversionDone(void)
{
    return (PIC8_REG8(PIC_REG_ADCON0) & PIC_ADCON0_GO_NDONE) ? 0U : 1U;   /* GO/nDONE: 1=in progress, hw clears when done. */
}

uint16_t EPIC_ADC_Read(void)
{
    uint8_t lo = PIC8_REG8(PIC_REG_ADRESL);
    uint8_t hi = PIC8_REG8(PIC_REG_ADRESH);
    /* Justification handled by hardware (ADFM); this just reassembles
     * the two bytes as written, no software shifting needed either
     * way per DS41364B's documented ADFM behavior, confirm this
     * during implementation rather than assuming. */
    return (uint16_t)(((uint16_t)hi << 8) | lo);
}

void ADC_IRQHandler(void)
{
    if (s_conv_cb) s_conv_cb();
}
```

```c
static uint16_t s_adc_channel_value[PIC16F193X_FAMILY_ADC_CH];

void pic16f193x_sim_adc_drive(uint8_t channel, uint16_t value_10bit)
{
    if (channel < PIC16F193X_FAMILY_ADC_CH) {
        s_adc_channel_value[channel] = (uint16_t)(value_10bit & 0x3FFU);
    }
}

static void sim_step_adc(void)
{
    uint8_t con0 = pic16f193x_sim_sfr[PIC_REG_ADCON0];
    if (!(con0 & PIC_ADCON0_GO_NDONE)) return;

    uint8_t ch = (uint8_t)((con0 & PIC_ADCON0_CHS_MASK) >> PIC_ADCON0_CHS_SHIFT);
    uint16_t value = (ch < PIC16F193X_FAMILY_ADC_CH) ? s_adc_channel_value[ch] : 0U;
    /* Right-justified assumed for the sim's own storage; if ADFM=0
     * (left-justified) is exercised by a test, extend this to check
     * ADCON1<ADFM> and shift accordingly, not implemented here since
     * the example (Task 7) uses the errata-safe default which is
     * right-justified. */
    pic16f193x_sim_sfr[PIC_REG_ADRESL] = (uint8_t)(value & 0xFFU);
    pic16f193x_sim_sfr[PIC_REG_ADRESH] = (uint8_t)(value >> 8);
    pic16f193x_sim_sfr[PIC_REG_ADCON0] = (uint8_t)(con0 & (uint8_t)~PIC_ADCON0_GO_NDONE);   /* Conversion "completes" in one sim step. */
}
```

```c
/**
 * @file    example_adc.c
 * @brief   ADC smoke test: init (errata-safe FRC clock), select
 *          channel 0, inject a known sim value, start + poll, read
 *          back and confirm.
 *
 * @details
 *   Expected register image (host sim, after init):
 *     ADCON0 = 0x01   (ADON=1, CHS=00000)
 *     ADCON1 = 0xB0   (ADFM=1, ADCS=011 FRC, ADPREF=00, ADNREF=0)
 *   After Start + one sim step (host) or a real conversion (target):
 *     ADRESL/ADRESH = the injected value (host) or a real ADC
 *     reading (target, not asserted numerically on target since
 *     there's no real analog input in the mdb gate, only the
 *     control-register state is checked there per Task 8).
 */

#include "pic16f193x.h"
#include "pic16f193x_sfr.h"
#include "peripherals/pic16f193x_gpio.h"
#include "peripherals/pic16f193x_adc.h"
#include "core/pic16f193x_wdt_sleep.h"
#include "core/epic_harness.h"

extern void pic16f193x_harness_halt(void);
#ifndef PIC8_HARNESS_TARGET
extern void pic16f193x_sim_adc_drive(uint8_t channel, uint16_t value_10bit);
#endif

int main(void)
{
    epic_harness_init();

    ADC_HandleTypeDef adc = ADC_HANDLE_DEFAULT;
    EPIC_ADC_Init(&adc);
    EPIC_ADC_SelectChannel(0U);

#ifndef PIC8_HARNESS_TARGET
    pic16f193x_sim_adc_drive(0U, 0x2AAU);   /* Arbitrary known value for the host-sim assertion. */
#endif

    EPIC_ADC_Start();
    while (!EPIC_ADC_IsConversionDone()) { /* spin; real target has real conversion latency, host sim completes in one step */ }
    uint16_t result = EPIC_ADC_Read();

    uint8_t con0 = PIC8_REG8(PIC_REG_ADCON0);
    uint8_t con1 = PIC8_REG8(PIC_REG_ADCON1);
    epic_harness_log("ADCON0=0x%02X ADCON1=0x%02X result=0x%03X\n", con0, con1, result);
#ifndef PIC8_HARNESS_TARGET
    int rc = epic_harness_report((con1 == 0xB0U) && (result == 0x2AAU));
#else
    int rc = epic_harness_report(con1 == 0xB0U);   /* Real target: only control-register state is asserted here. */
#endif
    pic16f193x_harness_halt();
    return rc;
}
```
