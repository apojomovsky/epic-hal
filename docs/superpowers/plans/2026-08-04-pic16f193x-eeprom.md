# Data EEPROM for pic16f193x-hal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Status: **implemented and cleared the §4 gate.** Peripheral #7 in
`docs/pic16f193x-plan.md` §7's roadmap table. All six 193X variants
have 256 bytes of data EEPROM (`docs/pic16f193x-plan.md` §1).

**Goal:** Land a `EPIC_EEPROM_*` driver for data EEPROM read/write
(DS41364B memory-programming chapter) through the §4 gate, scoped to
data EEPROM only (Non-goals covers program-memory self-write).

**Architecture:** Mirrors `pic16f87xa_eeprom.h`'s API shape
(`ReadByte`/`WriteByte`/`ReadBuffer`/`WriteBuffer`/`IsWriteComplete`).
The write path is the highest-risk part of this peripheral: the
unlock sequence (`EECON2=0x55; EECON2=0xAA; WR=1`) must execute with
no interruption, and `EECON1`'s `WR`/`WREN` bits are exactly the kind
of banked-register RMW that bit `pic16f193x-hal/docs/ARCHITECTURE.md`
Finding 2 (PIE1/2/3's plain-C RMW silently missed the bank on this
core). This plan flags that risk explicitly rather than assuming the
generic bit-set macros are safe here without the §4 gate confirming
it.

**Tech Stack:** C99, MPLAB XC8, gcc (host sim), CMake, GNU Make.

## Global Constraints

- C99, no compiler extensions in portable code. XC8 inline asm, if
  needed per Task 3's finding, follows the root `CLAUDE.md` rules: no
  operand constraints, only file-scope `static volatile` symbols
  addressable, leading `_` on PIC16 user globals in the asm string,
  SFRs don't need it, STATUS bits numeric not aliased.
- No em-dashes anywhere.
- Every register access is a compile-time-constant `PIC_REG_*` token.
- **Standing warning**: every bit position here was re-derived from
  DS41364B and cross-checked against the installed DFP header's
  `_EECON1_` `_POSN`/`_MASK` macros
  (`/opt/microchip/xc8/v3.10/pic/packs/Microchip.PIC12-16F1xxx_DFP/xc8/pic/include/proc/pic16f1937.h`).
  Timer1 shipped with a wrong bit position (`PIC_T1CON_TMR1CS` at bit
  1, copied from `pic16f87xa`'s classic-PIC16 T1CON, real field is
  bits 7:6) from a transcription without this cross-check.
- **Banked-RMW warning** (`pic16f193x-hal/docs/ARCHITECTURE.md`
  Finding 2): a plain-C read-modify-write against a runtime SFR
  address on this core can silently miss the bank (confirmed for
  PIE1/2/3, fixed via `__at(0x70)` scratch + inline-asm `movlb`).
  `EECON1`'s `WREN`/`WR` bit-sets are the same shape of operation on a
  different bank; do not assume the generic `PIC8_BIT_SET`/`PIC8_BIT_CLR`
  macros are safe here without the §4 gate (Task 8) confirming it. If
  the gate shows a mismatch, apply the same `__at(0x70)` + `movlb`
  fix pattern already proven for PIE1/2/3, don't invent a new one.

## Non-goals (not in this phase)

- Program-memory self-write / Flash erase-write (`EECON1<EEPGD>=1`,
  `CFGS`-controlled addressing space): a materially different, higher-
  risk unlock sequence with different timing, a separate follow-up.
  `EEADRH` stays 0 for pure data-EEPROM addressing in this driver.
- `EECON2` is write-only-unlock, not modeled as a normal readable SFR
  with bit fields (reads as an undefined/don't-care value per
  DS41364B); this driver only ever writes it, never reads it.

- [ ] **Step 1: Add EECON1 bit macros** (addresses

```c
/* Bank 3. EECON1, DS41364B memory-programming chapter. Verified
 * against the installed DFP header (pic16f1937.h) _EECON1_ POSN/MASK
 * macros; re-verify against DS41364B before relying on them. EECON2
 * is write-only unlock, no bit fields defined (see the driver's
 * Non-goals note). */
#define PIC_EECON1_RD           PIC8_BIT(0)
#define PIC_EECON1_WR           PIC8_BIT(1)
#define PIC_EECON1_WREN         PIC8_BIT(2)
#define PIC_EECON1_WRERR        PIC8_BIT(3)
#define PIC_EECON1_FREE         PIC8_BIT(4)   /* Flash-only, unused this phase (Non-goals). */
#define PIC_EECON1_LWLO         PIC8_BIT(5)   /* Flash-only, unused this phase. */
#define PIC_EECON1_CFGS         PIC8_BIT(6)   /* Must stay 0: data EEPROM space, not config/calibration. */
#define PIC_EECON1_EEPGD        PIC8_BIT(7)   /* Must stay 0: data EEPROM, not program memory. */
/* EECON1 POR = 0x00 (confirm against DS41364B). */

#define PIC_EEADRH_MASK         0x7FU
#define PIC_EEDATH_MASK         0x3FU
```

- [ ] **Step 2: Write the driver body**

```c
/**
 * @file    pic16f193x_eeprom.c
 * @brief   PIC16F193X data EEPROM driver implementation.
 */
#include "peripherals/pic16f193x_eeprom.h"
#include "pic16f193x_sfr.h"
#include "pic16f193x_platform.h"
#include "core/pic16f193x_irq.h"

static void (*s_write_cb)(void);

EPIC_StatusTypeDef EPIC_EEPROM_Init(void (*write_complete_cb)(void))
{
    s_write_cb = write_complete_cb;
    return EPIC_OK;
}

EPIC_StatusTypeDef EPIC_EEPROM_DeInit(void)
{
    PIC8_BIT_CLR(PIC8_REG8(PIC_REG_EECON1), PIC_EECON1_WREN);
    s_write_cb = 0;
    return EPIC_OK;
}

uint8_t EPIC_EEPROM_ReadByte(uint8_t addr)
{
    PIC8_REG8(PIC_REG_EEADRL) = addr;
    PIC8_REG8(PIC_REG_EEADRH) = 0x00U;   /* Data-EEPROM space (EEPGD=0, CFGS=0), single-byte address fits EEADRL alone this phase. */
    PIC8_BIT_SET(PIC8_REG8(PIC_REG_EECON1), PIC_EECON1_RD);
    return PIC8_REG8(PIC_REG_EEDATL);    /* RD self-clears; the read completes in the same cycle per DS41364B (no wait needed). */
}

EPIC_StatusTypeDef EPIC_EEPROM_WriteByte(uint8_t addr, uint8_t data)
{
    PIC8_REG8(PIC_REG_EEADRL) = addr;
    PIC8_REG8(PIC_REG_EEADRH) = 0x00U;
    PIC8_REG8(PIC_REG_EEDATL) = data;
    /* EEPGD=0, CFGS=0: data EEPROM space (POR default, not re-set
     * here since DeInit/Init never touch them; confirm this
     * assumption holds, or explicitly clear both bits here if the
     * register could be left in a program-memory-space state by
     * other code, don't assume the caller never touched EECON1). */
    PIC8_BIT_SET(PIC8_REG8(PIC_REG_EECON1), PIC_EECON1_WREN);

    /* Unlock sequence, DS41364B's documented shape (re-verify NOP
     * count / interrupt-disable window against the datasheet per
     * Task 3 Step 1, this is a best-effort transcription, not
     * independently re-confirmed cycle-by-cycle in this pass): */
    EPIC_IRQ_Disable();
    PIC8_REG8(PIC_REG_EECON2) = 0x55U;
    PIC8_REG8(PIC_REG_EECON2) = 0xAAU;
    PIC8_BIT_SET(PIC8_REG8(PIC_REG_EECON1), PIC_EECON1_WR);
    EPIC_IRQ_Enable();

    while (PIC8_REG8(PIC_REG_EECON1) & PIC_EECON1_WR) { /* spin until hardware clears WR */ }

    PIC8_BIT_CLR(PIC8_REG8(PIC_REG_EECON1), PIC_EECON1_WREN);

    if (PIC8_REG8(PIC_REG_EECON1) & PIC_EECON1_WRERR) return EPIC_ERROR;
    return EPIC_OK;
}

uint8_t EPIC_EEPROM_IsWriteComplete(void)
{
    return (PIC8_REG8(PIC_REG_EECON1) & PIC_EECON1_WR) ? 0U : 1U;
}

uint8_t EPIC_EEPROM_HasWriteError(void)
{
    return (PIC8_REG8(PIC_REG_EECON1) & PIC_EECON1_WRERR) ? 1U : 0U;
}

void EEPROM_IRQHandler(void)
{
    if (s_write_cb) s_write_cb();
}
```

Confirm the exact platform macro names (`PIC8_REG8`,
`PIC8_BIT_SET`/`_CLR`) and `EPIC_IRQ_Disable`/`EPIC_IRQ_Enable`'s exact
signatures against fresh reads of `pic16f193x_timer1.c` and
`pic16f193x_irq.h` before finalizing. **This is the task where the
banked-RMW risk (Global Constraints) is most concentrated**: if the §4

```c
static uint8_t s_eeprom_data[EEPROM_SIZE_BYTES];

static void sim_step_eeprom(void)
{
    uint8_t econ1 = pic16f193x_sim_sfr[PIC_REG_EECON1];
    if (econ1 & PIC_EECON1_RD) {
        uint8_t addr = pic16f193x_sim_sfr[PIC_REG_EEADRL];
        pic16f193x_sim_sfr[PIC_REG_EEDATL] = s_eeprom_data[addr];
        pic16f193x_sim_sfr[PIC_REG_EECON1] = (uint8_t)(econ1 & (uint8_t)~PIC_EECON1_RD);
    } else if (econ1 & PIC_EECON1_WR) {
        uint8_t addr = pic16f193x_sim_sfr[PIC_REG_EEADRL];
        s_eeprom_data[addr] = pic16f193x_sim_sfr[PIC_REG_EEDATL];
        pic16f193x_sim_sfr[PIC_REG_EECON1] = (uint8_t)(econ1 & (uint8_t)~PIC_EECON1_WR);
        /* EE interrupt flag: handled by the existing PIR/PIE table
         * per docs/pic16f193x-plan.md §7's note that it needs zero
         * changes; this step only needs to model the data-array
         * effect and clear WR, not set the flag directly. */
    }
}
```

```c
/**
 * @file    example_eeprom.c
 * @brief   EEPROM smoke test: write a known byte, read it back,
 *          confirm via the MODE=gpio RA0-marker gate.

 * @details
 *   Writes 0xA5 to address 0x00, reads it back. Pass = readback

#include "pic16f193x.h"
#include "pic16f193x_sfr.h"
#include "peripherals/pic16f193x_gpio.h"
#include "peripherals/pic16f193x_eeprom.h"

#include "core/pic8_harness.h"

extern void pic16f193x_harness_halt(void);

int main(void)
{
    pic8_harness_init();

    EPIC_EEPROM_Init(0);
    EPIC_StatusTypeDef wr = EPIC_EEPROM_WriteByte(0x00U, 0xA5U);
    uint8_t readback = EPIC_EEPROM_ReadByte(0x00U);
    uint8_t err = EPIC_EEPROM_HasWriteError();

    pic8_harness_log("wr=%d readback=0x%02X err=%u\n", (int)wr, readback, (unsigned)err);
    int rc = pic8_harness_report((wr == EPIC_OK) && (readback == 0xA5U) && !err);
    pic16f193x_harness_halt();
    return rc;
}
```
