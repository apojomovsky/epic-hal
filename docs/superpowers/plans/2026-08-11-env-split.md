# HAL src/ Environment Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Status: **approved 2026-08-11, in progress**.

**Goal:** Make each HAL's `src/` structure mirror its environments: `src/core/` shared, `src/target/` real-hardware twins, `src/sim/` host-sim, `src/mdb/` MPLAB-SIM gate (renamed from `*_harness_sim_target.c`); add the README warnings; add a bundle-gate assertion that no `_sim`/`_mdb` file can ship in a release.

**Architecture:** Pure file moves + path updates, no content change. The manifest is the single source of truth; every consumer (CMakeLists, reference projects, bundlegen, script tests) is updated in lockstep. Verified by the existing gates (per-module ctest, doxygen checker, script tests, bundle dry-run).

**Tech Stack:** git mv, TOML manifest, CMake, MPLAB X project XML, Python (make_bundle.py, tests).

## Global Constraints

- No em-dash characters in added lines or commit messages; Conventional Commits.
- No content changes: files move, the mdb harness is renamed; code bodies and docstrings are untouched. The doxygen checker must stay green (docstrings move with their files).
- Third-party untouched.
- The move map (canonical, per HAL, mirror names):
  - `<fam>_isr_vector.c`, `<fam>_wdt_sleep_target.c` -> `src/target/`
  - `<fam>_harness_sim.c`, `<fam>_wdt_sleep_sim.c` -> `src/sim/`
  - `<fam>_harness_sim_target.c` -> `src/mdb/<fam>_harness_mdb.c`
  - everything else in `src/core/` and `src/peripherals/` stays
- The pre-commit hook runs on every commit (worktree-scoped, cppcheck-robust). Never bypass.
- The ephemeral-plans convention applies: this spec and plan are deleted when the work lands.
