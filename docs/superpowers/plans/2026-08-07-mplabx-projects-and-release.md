# MPLAB X Projects and v0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one reference MPLAB X project per family inside each bundle, and publish `v0.1.0` as a GitHub Release with all three bundles attached and gated.

**Architecture:** Three committed `.X` projects live under `examples/` in the repo, one per family, seeded from the surviving `pic16f87xa-hal/mcu/pic16f87xa-mplabx/nbproject`. `make_bundle.py` copies the matching one into each bundle as `examples/epicurus-demo.X`. A tag-triggered workflow regenerates every bundle, runs the isolation gate against it, and attaches the tarballs plus `SHA256SUMS` to a Release.

**Tech Stack:** MPLAB X IDE v6.35 project format (`nbproject`), Python 3.11+ (stdlib only), MPLAB XC8 v4.00, Docker, GitHub Actions, `gh` CLI.

**Design spec:** `docs/superpowers/specs/2026-08-05-distribution-design.md`, phases 4 and 5.

**Prerequisites:** both earlier plans complete. `bundle-gate` must be green on `master`.

## Global Constraints

- **No em-dashes.** A pre-commit hook rejects them.
- **Python 3.11 minimum**, stdlib only. Tests use `unittest`.
- **Do not modify `docker/ci-toolchain/Dockerfile`.** No python3 in the container.
- **`nbproject` files are generated by MPLAB X and pin DFP versions.** Commit only what is needed to open and build; never hand-edit generated XML beyond the specific fields this plan names.
- **Three `.X` projects, not more.** Mirroring the old per-module `mcu/` layout would mean 29 `nbproject` trees, which rot. If a fourth seems necessary, stop and reconsider.
- **The release is `v0.1.0`.** `0.x` signals the `epicurus.mk` interface may still move. Release notes must say so.
- **Nothing generated is committed.** Bundles stay gitignored.
- **Conventional Commits**, trailing newline, no trailing whitespace.

/*
 * Epicurus reference project, PIC16F87XA.
 *
 * The smallest thing that proves the bundle is wired up correctly: set
 * up a 1 ms tick and toggle RB0 from it. If this builds and runs, your
 * include paths, source folders, and device pack are all right, and you
 * can copy this project's settings into your own.
 *
 * See MPLABX.md in this bundle for adding Epicurus to an existing
 * project instead.
 */
#include <xc.h>

#include "epic_tick.h"
#include "pic16f87xa_gpio.h"

#pragma config FOSC = HS
#pragma config WDTE = OFF
#pragma config PWRTE = ON
#pragma config BOREN = ON
#pragma config LVP = OFF
#pragma config CPD = OFF
#pragma config WRT = OFF
#pragma config CP = OFF

int main(void)
{
    EPIC_GPIO_Init();
    EPIC_GPIO_SetPinDirection(EPIC_GPIO_PORTB, 0, EPIC_GPIO_OUTPUT);
    EPIC_Tick_Init();

    uint32_t last = EPIC_Tick_Get();
    for (;;) {
        if ((EPIC_Tick_Get() - last) >= 500u) {
            last = EPIC_Tick_Get();
            EPIC_GPIO_TogglePin(EPIC_GPIO_PORTB, 0);
        }
    }
}
```

Verify every symbol against the real headers before building; the HAL's exact function names are in `pic16f87xa-hal/MANUAL.md` and `epic-tick/docs/API.md`. If a name here does not match, fix this file, not the HAL.

```python
def reference_project_dir(manifest, family_name: str) -> str:
    """Where this family's reference MPLAB X project lives in the repo.

    Derived from the family's hal_dir so adding a family does not need a
    second lookup table to be kept in sync.
    """
    fam = _family(manifest, family_name)
    slug = fam.hal_dir.removesuffix("-hal")
    return f"examples/epicurus-demo-{slug}.X"
```

- [ ] **Step 4: Copy it in make_bundle.py**

In `scripts/make_bundle.py`, add `nbproject` handling. First, remove `"mcu"` from `SKIP_DIRS`' effect on the project copy by writing a dedicated copier, since `nbproject` holds `.xml`, `.mk`, and `.properties` files that the source filter would drop:

```python
def _copy_project(src: pathlib.Path, dst: pathlib.Path) -> None:
    """Copy an MPLAB X .X project wholesale.

    Unlike a source tree, everything here matters: nbproject holds .xml,
    .mk, and .properties files, and a project missing any of them opens
    broken. Only build output is skipped.
    """
    for path in sorted(src.rglob("*")):
        parts = path.relative_to(src).parts
        if "build" in parts or "dist" in parts or "__pycache__" in parts:
            continue
        if path.is_dir():
            continue
        target = dst / path.relative_to(src)
        target.parent.mkdir(parents=True, exist_ok=True)
        shutil.copy2(path, target)
```

Then, in `main()`, after the generated files are written and before the missing-files check:

```python
    project_src = REPO / bundlegen.reference_project_dir(manifest, args.family)
    if not project_src.is_dir():
        sys.exit(f"error: no reference project at {project_src.relative_to(REPO)}")
    _copy_project(project_src, root / "examples" / "epicurus-demo.X")
```

## Task 5: The release workflow

**Files:**
- Create: `.github/workflows/release-bundles.yml`

**Interfaces:**
- Consumes: `make_bundle.py`, the isolation gate's approach.
- Produces: a GitHub Release with three tarballs and `SHA256SUMS`.

The release **must not** publish anything it has not built. Bundles are generated, gated by an isolated build, and only then uploaded.

- [ ] **Step 1: Write the workflow**

Create `.github/workflows/release-bundles.yml`:

```yaml
name: release-bundles

# Tag-triggered: builds one source bundle per family, proves each one
# builds from a scratch directory outside any repo checkout, and only
# then attaches the tarballs to a GitHub Release.
#
# Nothing generated is committed; bundles exist only as release assets.
# The gate is the same idea as bundle-gate.yml, repeated here because a
# release must never publish an artifact it has not itself built.

on:
  push:
    tags: ["v*"]
  workflow_dispatch:
    inputs:
      version:
        description: "Version to build (e.g. v0.1.0), for a dry run"
        required: true

permissions:
  contents: write
  packages: read

jobs:
  toolchain-image:
    runs-on: ubuntu-latest
    outputs:
      image: ${{ steps.resolve.outputs.image }}
    steps:
      - uses: actions/checkout@v4
      - id: resolve
        run: |
          xc8_version="$(grep -m1 '^ARG XC8_VERSION=' docker/ci-toolchain/Dockerfile | cut -d= -f2)"
          pic16_dfp_version="$(grep -m1 '^ARG PIC16FXXX_DFP_VERSION=' docker/ci-toolchain/Dockerfile | cut -d= -f2)"
          pic18_dfp_version="$(grep -m1 '^ARG PIC18FXXXX_DFP_VERSION=' docker/ci-toolchain/Dockerfile | cut -d= -f2)"
          pic1216f1_dfp_version="$(grep -m1 '^ARG PIC12_16F1XXX_DFP_VERSION=' docker/ci-toolchain/Dockerfile | cut -d= -f2)"
          mplabx_version="$(grep -m1 '^ARG MPLABX_VERSION=' docker/ci-toolchain/Dockerfile | cut -d= -f2)"
          tag="xc8-v${xc8_version}-dfp${pic16_dfp_version}-${pic18_dfp_version}-${pic1216f1_dfp_version}-mplabx${mplabx_version}"
          echo "image=ghcr.io/${{ github.repository_owner }}/pic8-hal-ci:${tag}" >> "$GITHUB_OUTPUT"
      - run: echo "${{ secrets.GITHUB_TOKEN }}" | docker login ghcr.io -u "${{ github.actor }}" --password-stdin
      - run: docker pull "${{ steps.resolve.outputs.image }}"

  build:
    runs-on: ubuntu-latest
    outputs:
      version: ${{ steps.version.outputs.version }}
    steps:
      - uses: actions/checkout@v4
      - id: version
        run: |
          if [ "${{ github.event_name }}" = "workflow_dispatch" ]; then
            version="${{ inputs.version }}"
          else
            version="${GITHUB_REF#refs/tags/}"
          fi
          echo "version=$version" >> "$GITHUB_OUTPUT"
          echo "Building $version"
      - name: Generate every family's bundle
        run: |
          python3 - <<'PY' > families.txt
          import sys
          sys.path.insert(0, "scripts")
          import epicmanifest
          m = epicmanifest.load(epicmanifest.default_path())
          for name in sorted(m.families):
              print(name)
          PY
          while read -r fam; do
            python3 scripts/make_bundle.py \
              --family "$fam" --version "${{ steps.version.outputs.version }}"
          done < families.txt
      - name: Checksum the tarballs
        run: |
          cd bundles
          sha256sum ./*.tar.gz > SHA256SUMS
          cat SHA256SUMS
      - uses: actions/upload-artifact@v4
        with:
          name: release-bundles
          path: bundles/

  gate:
    needs: [toolchain-image, build]
    runs-on: ubuntu-latest
    container:
      image: ${{ needs.toolchain-image.outputs.image }}
      credentials:
        username: ${{ github.actor }}
        password: ${{ secrets.GITHUB_TOKEN }}
    steps:
      - uses: actions/download-artifact@v4
        with:
          name: release-bundles
          path: /tmp/bundles
      - name: Verify the checksums
        run: cd /tmp/bundles && sha256sum -c SHA256SUMS
      - name: Build every bundle outside any repo checkout
        shell: bash
        run: |
          # /isolated has no repo above it, so a path escaping a bundle
          # cannot accidentally resolve through the source tree.
          mkdir -p /isolated && cd /isolated
          fail=0
          for tarball in /tmp/bundles/*.tar.gz; do
            name="$(basename "$tarball" .tar.gz)"
            tar xzf "$tarball" -C /isolated
            cd "/isolated/$name"

            for required in epicurus.mk epicurus-sources.json SUPPORT.md \
                            QUICKSTART.md MPLABX.md VERSION LICENSE; do
              if [ ! -f "$required" ]; then
                echo "FAIL $name: missing $required"
                fail=1
              fi
            done
            if [ ! -d examples/epicurus-demo.X ]; then
              echo "FAIL $name: missing examples/epicurus-demo.X"
              fail=1
            fi

            module="$(grep -m1 '^EPICURUS_MODULE_' epicurus.mk \
              | sed 's/^EPICURUS_MODULE_\([^ ]*\).*/\1/' || true)"
            if [ -z "$module" ]; then
              echo "SKIP $name: HAL-only bundle, nothing to link"
              cd /isolated
              continue
            fi
            part="$(grep -m1 "^EPICURUS_SUPPORTED_epic-$module " epicurus.mk \
              | awk '{print $3}')"
            dfp_name="$(grep -m1 '^EPICURUS_DFP' epicurus.mk | awk '{print $3}')"

            cat > Makefile <<EOF
          EPICURUS_DIR := .
          EPICURUS_MCU := $part
          EPICURUS_MODULES := $module
          include \$(EPICURUS_DIR)/epicurus.mk
          DFP := $XC8_INSTALL_DIR/pic/packs/$dfp_name/xc8
          all:
          	xc8-cc -mdfp=\$(DFP) -mcpu=\$(shell echo \$(EPICURUS_MCU) | tr A-Z a-z) \\
          	  -O2 -std=c99 -Wall -Wextra \$(EPICURUS_CFLAGS) -DFOSC_HZ=20000000 \\
          	  \$(EPICURUS_SRCS) main.c -o app.hex -ginhx32
          EOF
            printf 'void main(void) { for (;;) { } }\n' > main.c

            if make >build.log 2>&1 && [ -f app.hex ]; then
              echo "PASS $name ($module on $part)"
            else
              echo "FAIL $name ($module on $part)"
              cat build.log
              fail=1
            fi
            cd /isolated
          done
          exit "$fail"

  publish:
    needs: [build, gate]
    if: github.event_name == 'push'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/download-artifact@v4
        with:
          name: release-bundles
          path: bundles
      - name: Write the release notes
        run: |
          version="${{ needs.build.outputs.version }}"
          {
            echo "## Epicurus $version"
            echo
            echo "Source bundles, one per family. Download the one for your"
            echo "part, unpack it, and point \`EPICURUS_DIR\` at it. Each"
            echo "bundle carries its own \`QUICKSTART.md\`, \`SUPPORT.md\`,"
            echo "\`MPLABX.md\`, and a reference MPLAB X project under"
            echo "\`examples/\`."
            echo
            echo '```make'
            echo 'EPICURUS_DIR := third_party/epicurus'
            echo 'EPICURUS_MCU := 16F877A'
            echo 'EPICURUS_MODULES := serial tick'
            echo 'include $(EPICURUS_DIR)/epicurus.mk'
            echo
            echo 'SRCS := main.c $(EPICURUS_SRCS)'
            echo 'CFLAGS += $(EPICURUS_CFLAGS)'
            echo '```'
            echo
            echo "### Stability"
            echo
            echo "This is a 0.x release: the \`epicurus.mk\` interface may"
            echo "still change. Pin this tag rather than tracking a branch."
            echo
            echo "### Support"
            echo
            echo "Not every module builds on every part; the smaller parts"
            echo "in each family run out of RAM for the larger modules."
            echo "Each bundle's \`SUPPORT.md\` has the full table with a"
            echo "reason for every exclusion, and \`epicurus.mk\` fails"
            echo "immediately with that reason rather than as a wall of XC8"
            echo "linker errors."
            echo
            echo "### Verification"
            echo
            echo "Every bundle in this release was built from a scratch"
            echo "directory outside the repository before publication."
            echo
            echo '```'
            cat bundles/SHA256SUMS
            echo '```'
          } > notes.md
          cat notes.md
      - name: Create the release
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          gh release create "${{ needs.build.outputs.version }}" \
            --title "Epicurus ${{ needs.build.outputs.version }}" \
            --notes-file notes.md \
            bundles/*.tar.gz bundles/SHA256SUMS
```
