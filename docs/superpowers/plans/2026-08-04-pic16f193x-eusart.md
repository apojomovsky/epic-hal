# EUSART for pic16f193x-hal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Status: **written, not yet implemented.** Peripheral #3 in
`docs/pic16f193x-plan.md` §7's roadmap table. Landing this also
unlocks a future `HARNESS=sim` UART-reporting build for later
peripherals (an alternative to `MODE=gpio`), but that harness variant
is NOT built by this plan, only the driver itself; this plan's own §4
gate uses the same `MODE=gpio` RA0-marker protocol every other 193X
peripheral uses.

**Goal:** Land a `HAL_USART_*` driver for asynchronous 8-bit TX/RX
(DS41364B §23.0) through the §4 gate.

**Architecture:** Mirrors `pic16f87xa_usart.{h,c}`'s Cube-style handle
and API almost exactly (same register roles: RCREG/TXREG/SPBRGL/H/
RCSTA/TXSTA/BAUDCON, same SPBRG-divisor-formula shape), scoped to
async, 8-bit, non-auto-baud mode this phase (Non-goals).

**Tech Stack:** C99, MPLAB XC8, gcc (host sim), CMake, GNU Make.

## Global Constraints

- C99, no compiler extensions. No em-dashes anywhere.
- Every register access is a compile-time-constant `PIC_REG_*` token.
- Handle-copy convention: copy by value, never store the pointer.
- **Standing warning**: every bit position here was re-derived from
  DS41364B and cross-checked against the installed DFP header's
  `_RCSTA_`/`_TXSTA_`/`_BAUDCON_` `_POSN`/`_MASK` macros
  (`/opt/microchip/xc8/v3.10/pic/packs/Microchip.PIC12-16F1xxx_DFP/xc8/pic/include/proc/pic16f1937.h`).
  Timer1 shipped with a wrong bit position (`PIC_T1CON_TMR1CS` at bit
  1, copied from `pic16f87xa`'s classic-PIC16 T1CON, real field is
  bits 7:6) from a transcription without this cross-check. Never trust
  a bit position from another family's driver or memory alone.
- Per `docs/pic16f193x-plan.md` §8's risk list: "sanity-check computed
  divisors against the register width." `USART_ComputeSPBRG`'s
  BRGH/BRG16 table must be re-derived from DS41364B directly (there
  are 4 combinations), not assumed from `pic16f87xa_usart.c`'s 2 (this
  family adds `BRG16`, an extra dimension that family doesn't have).

## Non-goals (not in this phase)

- 9-bit addressed mode (`RX9`/`TX9`/`ADDEN`): deferred, mirrors this
  codebase's existing scope-cut convention.
- Auto-baud detection (`ABDEN`): DS80000479 flags a real "EUSART
  auto-baud SPBRG bug" on this silicon (`docs/pic16f193x-plan.md` §1);
  this is the actual reason it's deferred, not driver-author
  convenience.
- Synchronous mode (`SYNC=1`): a materially different clock-source
  model, deferred alongside 9-bit mode.
- `BRG16=1` (16-bit baud generator): included in the divisor-formula
  table (Task 3) since it costs nothing to compute correctly, but not
  exercised by the default handle or the example; the driver accepts
  it as a valid `BaudHigh`-adjacent config if the caller sets it
  explicitly (confirm during implementation whether this needs its own
  handle field or is folded into an existing one, don't silently drop
  the BRG16=1 divisor table entries just because the example doesn't
  use them).

```c
/**
 * @file    pic16f193x_usart.h
 * @brief   PIC16F193X EUSART driver, asynchronous 8-bit mode only
 *          this phase (9-bit, auto-baud, synchronous deferred, see
 *          the plan's Non-goals; auto-baud specifically due to a
 *          real DS80000479 SPBRG errata, not convenience).
 * @details Source: DS41364B Register 23-2/23-3/23-4, DS41364B §23.0.
 *          API shape mirrors pic16f87xa_usart.h. Full reference:
 *          MANUAL.md §14.
 */
#ifndef PIC16F193X_USART_H
#define PIC16F193X_USART_H

#include <stdint.h>
#include "core/hal_status.h"

#ifdef __cplusplus
extern "C" {
#endif

typedef enum {
    USART_BRGH_LOW  = 0x0U,   /**< BRGH=0, BRG16=0: divisor 64. */
    USART_BRGH_HIGH = 0x1U,   /**< BRGH=1, BRG16=0: divisor 16. */
} USART_BaudRateHighTypeDef;

/**
 * @brief Compute the SPBRG value for a desired baud rate, BRG16=0
 *        (8-bit SPBRGL only) this phase.
 *   rate = FOSC / (64 x (X+1))  (BRGH=0)
 *   rate = FOSC / (16 x (X+1))  (BRGH=1)
 * Returns 0..255, or 0xFFFF if X would exceed 255 (does not fit the
 * 8-bit register, per docs/pic16f193x-plan.md §8's divisor-width
 * risk note, this is a hard rejection, not a silent truncation).
 */
uint16_t USART_ComputeSPBRG(uint32_t fosc_hz, uint32_t baud,
                            USART_BaudRateHighTypeDef brgh);

typedef struct {
    USART_BaudRateHighTypeDef BaudHigh;
    uint8_t                   SPBRG;          /**< 0..255, pre-computed via USART_ComputeSPBRG. */
    void (*TxCpltCallback)(void);              /**< Fires on TXIF; NULL = no callback. */
    void (*RxCpltCallback)(uint8_t data);       /**< Fires on RCIF; NULL = no callback. */
} USART_HandleTypeDef;

#define USART_HANDLE_DEFAULT { .BaudHigh = USART_BRGH_HIGH, .SPBRG = 0U, .TxCpltCallback = 0, .RxCpltCallback = 0 }

HAL_StatusTypeDef HAL_USART_Init(const USART_HandleTypeDef *h);
HAL_StatusTypeDef HAL_USART_DeInit(void);
void HAL_USART_Transmit(uint8_t data);
uint8_t HAL_USART_IsTxShiftRegisterEmpty(void);   /**< TRMT. */
uint8_t HAL_USART_Receive(void);
uint8_t HAL_USART_HasOverrunError(void);          /**< OERR; must CREN-clear/set to recover. */

void USART_RX_IRQHandler(void) PIC8_WEAK;
void USART_TX_IRQHandler(void) PIC8_WEAK;

#ifdef __cplusplus
}
#endif
#endif /* PIC16F193X_USART_H */
```

## Task 3: Add `pic16f193x_usart.c` (driver implementation)

**Files:** Create `pic16f193x-hal/src/peripherals/pic16f193x_usart.c`.

- [ ] **Step 1: Write `USART_ComputeSPBRG`**

```c
uint16_t USART_ComputeSPBRG(uint32_t fosc_hz, uint32_t baud,
                            USART_BaudRateHighTypeDef brgh)
{
    if (baud == 0U) return 0xFFFFU;
    uint32_t divisor = (brgh == USART_BRGH_HIGH) ? 16U : 64U;
    uint32_t x = (fosc_hz / (divisor * baud));
    if (x == 0U) return 0xFFFFU;   /* baud too high for this Fosc/BRGH combo. */
    x -= 1U;
    if (x > 255U) return 0xFFFFU;  /* Doesn't fit SPBRGL's 8-bit width, reject rather than truncate. */
    return (uint16_t)x;
}
```

Re-derive this formula's two rows (BRGH=0/1, BRG16=0 both) against
DS41364B's actual baud-rate-formula table before finalizing; this was
written from the general EUSART BRG shape, not independently
re-confirmed against this specific datasheet's table in this pass.

- [ ] **Step 2: Write the driver body**

```c
/**
 * @file    pic16f193x_usart.c
 * @brief   PIC16F193X EUSART driver implementation, async 8-bit only.
 */
#include "peripherals/pic16f193x_usart.h"
#include "pic16f193x_sfr.h"
#include "pic16f193x_platform.h"

static void (*s_tx_cb)(void);
static void (*s_rx_cb)(uint8_t data);

HAL_StatusTypeDef HAL_USART_Init(const USART_HandleTypeDef *h)
{
    if (!h) return HAL_INVALID;
    if (h->SPBRG > 0xFFU) return HAL_INVALID;   /* Redundant given the uint8_t field, kept as an explicit boundary check. */

    PIC8_REG8(PIC_REG_SPBRGL) = h->SPBRG;
    PIC8_REG8(PIC_REG_SPBRGH) = 0x00U;          /* BRG16=0 this phase: SPBRGH unused. */

    uint8_t txsta = PIC_TXSTA_TXEN;             /* SYNC=0 (async), CSRC=0 (n/a in async). */
    if (h->BaudHigh == USART_BRGH_HIGH) txsta |= PIC_TXSTA_BRGH;
    PIC8_REG8(PIC_REG_TXSTA) = txsta;

    PIC8_REG8(PIC_REG_RCSTA) = (uint8_t)(PIC_RCSTA_SPEN | PIC_RCSTA_CREN);
    PIC8_REG8(PIC_REG_BAUDCON) = 0x00U;         /* BRG16=0, ABDEN=0, SCKP=0. */

    s_tx_cb = h->TxCpltCallback;
    s_rx_cb = h->RxCpltCallback;

    return HAL_OK;
}

HAL_StatusTypeDef HAL_USART_DeInit(void)
{
    PIC8_REG8(PIC_REG_TXSTA) = 0x02U;   /* Back to POR (TRMT=1). */
    PIC8_REG8(PIC_REG_RCSTA) = 0x00U;
    s_tx_cb = 0;
    s_rx_cb = 0;
    return HAL_OK;
}

void HAL_USART_Transmit(uint8_t data)
{
    PIC8_REG8(PIC_REG_TXREG) = data;   /* TXIF clears on write, per DS41364B; not readable-then-clearable. */
}

uint8_t HAL_USART_IsTxShiftRegisterEmpty(void)
{
    return (PIC8_REG8(PIC_REG_TXSTA) & PIC_TXSTA_TRMT) ? 1U : 0U;
}

uint8_t HAL_USART_Receive(void)
{
    return PIC8_REG8(PIC_REG_RCREG);   /* Reading clears RCIF and advances the 2-deep FIFO. */
}

uint8_t HAL_USART_HasOverrunError(void)
{
    return (PIC8_REG8(PIC_REG_RCSTA) & PIC_RCSTA_OERR) ? 1U : 0U;
}

void USART_TX_IRQHandler(void)
{
    if (s_tx_cb) s_tx_cb();
}

void USART_RX_IRQHandler(void)
{
    uint8_t data = PIC8_REG8(PIC_REG_RCREG);
    if (s_rx_cb) s_rx_cb(data);
}
```

Confirm the exact platform macro names against a fresh read of
`pic16f193x_timer1.c` before finalizing. Note `OERR` recovery
(clearing `CREN` then setting it again) is NOT implemented here as an
automatic behavior, only exposed via `HAL_USART_HasOverrunError`; if
the reference driver auto-recovers, match that behavior instead,
check `pic16f87xa_usart.c`'s actual `HAL_USART_Receive` body for this
before finalizing.

static void sim_step_usart(void)
{
    uint8_t txsta = pic16f193x_sim_sfr[PIC_REG_TXSTA];
    if (txsta & PIC_TXSTA_TXEN) {
        /* Model transmission as instantaneous: TRMT stays 1 (shift
         * register always "empty" from the sim's point of view, no
         * real UART wire to drain onto), TXIF flag-setting is handled
         * by the existing PIR/PIE table (per docs/pic16f193x-plan.md
         * §7's note that the descriptor table needs zero changes),
         * this function only needs to keep TRMT correct. */
        pic16f193x_sim_sfr[PIC_REG_TXSTA] = (uint8_t)(txsta | PIC_TXSTA_TRMT);
    }
    /* RX: no real external byte source in the host sim; a test
     * injects a received byte via a caller-facing hook (mirror the
     * FVR/CPS plans' injection-hook naming convention, e.g.
     * pic16f193x_sim_usart_inject_rx(uint8_t byte), which writes
     * RCREG and sets RCIF directly), rather than this step function
     * fabricating one on its own. Implement that injection hook as
     * part of this task. */
}

/**
 * @file    example_eusart.c
 * @brief   EUSART smoke test: init at a known baud, transmit one
 *          byte, confirm control-register state via the MODE=gpio
 *          RA0-marker gate (not a UART loopback).

 * @details

 *     arithmetic during implementation, don't trust it blindly.

 *   Expected register image (host sim, after init + one Transmit):
 *     TXSTA  = 0x26   (TXEN=1, BRGH=1, TRMT=1 after the sim step)

#include "core/pic16f193x_wdt_sleep.h"
#include "core/pic8_harness.h"

extern void pic16f193x_harness_halt(void);

#ifndef FOSC_HZ
#define FOSC_HZ 32000000UL
#endif

    USART_HandleTypeDef usart = USART_HANDLE_DEFAULT;

    int rc = pic8_harness_report((txsta == 0x26U) && (rcsta == 0x90U) && (spbrgl == 0xCFU));
    pic16f193x_harness_halt();

}
